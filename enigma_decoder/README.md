# エニグマ暗号文単独攻撃ツール

エニグマ M3（陸軍3ローター式、リフレクター B）の暗号文を、平文の手がかり
（クリブ）なしで復号するツールです。英語と日本語ローマ字の両方に対応。

## ファイル構成

```
enigma_breaker/
├── enigma.py     # エニグマM3シミュレータ（自前実装）
├── corpora.py    # 言語モデル構築用の英文・ローマ字コーパス
├── scoring.py    # n-gram 言語スコアリング
├── attack.py     # Gillogly 二段階攻撃
├── decrypt.py    # コマンドラインエントリ
└── README.md     # このファイル
```

外部依存ゼロ（標準ライブラリのみ）。Python 3.7+ で動作。

## 使い方

```bash
# 動作確認（既知平文での自己テスト）
python decrypt.py --selftest

# 実際の暗号文を解読（自動言語判定）
python decrypt.py UKGYSQUMTYQWKCQLQFPKSXYZ...

# 言語を指定
python decrypt.py --lang english <暗号文>
python decrypt.py --lang romaji  <暗号文>

# 高速モード（精度低下、時間1/4程度）
python decrypt.py --quick <暗号文>
```

ツールは上位5候補を提示します。スコア差が大きい（>0.5程度）なら第1候補がほぼ
確実に正解です。差が小さい（<0.2）なら複数候補を目視確認してください。

## アルゴリズム

### Phase 1: ローター・初期位置の全探索
- ローター I-V から3つ選ぶ全 60 通り × 初期位置 26³ = 約 100 万通り
- 各設定で先頭 100 文字をプラグボード無しで復号
- 英語・ローマ字両方の trigram 対数確率の最大値でランク付け
- 上位 200 候補を Phase 2 へ

### Phase 2: プラグボードの山登り推定
- 各候補について、プラグボード接続を 1 ペアずつ追加
- 各反復で全 (a, b) 組合せ（最大 325 通り）を試して最良を選択
- スコアが改善しなくなるか 8 ペアに達するまで継続
- 言語非依存スコア（混合 n-gram）で最終ランキング

### Refine: リング設定の補正
- 上位候補について右ローターのリング設定を 26 通り再探索
- ノッチ越えタイミングが変わると結果が変化するため

## 想定実行時間

## 解読の現実的な限界

短文＋クリブ無し＋プラグボードあり、というのはエニグマ攻撃の中で**最も難しい**
シナリオです。結果は以下に強く依存します：

**暗号文長**:
- 200文字以上 → 安定して解読可能
- 100〜200文字 → ほぼ解読可能、上位候補確認推奨
- 50〜100文字 → 運次第、複数候補を目視判断
- 50文字未満 → 統計的に信頼不能

**プラグボード接続数**:
- 0〜3 ペア → 高確率で成功
- 4〜5 ペア → 短文では失敗率が上がる
- 6 ペア以上 → 短文では原理的に困難（軍用級設定）

カジュアルな暗号通信（友人間など）では通常 0〜3 ペアなので問題ありません。

## カスタマイズのヒント

**精度を上げたい場合**:
- `--top 500 --max-cand 200` で探索を広げる（時間は数倍）
- `corpora.py` の `ENGLISH_CORPUS` / `ROMAJI_CORPUS` を実際の友人の文体に
  近いテキストで増強する

**速度を上げたい場合**:
- `--quick` または `--top 80 --max-cand 20`
- 内部ループを NumPy / Cython で書き直すと 10〜100 倍速くなる

**M4（4ローター海軍式）に対応したい場合**:
- `enigma.py` に第4ローター（β/γ）と薄型リフレクター（B-thin/C-thin）を追加
- 探索空間が約 26 倍になるので並列化推奨

## 既知の限界

- リフレクター B のみ対応（C は `enigma.py` に定義済みだが攻撃ループは B 固定）
- リング設定は右ローターのみ最適化（中・左は短文ではほぼ影響なし）
- プラグボード山登りは局所最適に陥る可能性あり（複数開始点で試すと改善可能）
